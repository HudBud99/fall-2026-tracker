# HW Schedules

Put the files your AI assistant should read here, one or more per class:

- **`.txt` files of copied and pasted text.** This works best. For example, open the class's Grades or Assignments page, select everything, copy, and paste it into `BIO_100.txt`.
- **Screenshots, whenever copying and pasting doesn't work.** Examples: pages that won't let you select text, schedules that are images, or pasted text that comes out scrambled. Name them `BIO_100_1.png`, `BIO_100_2.png`, and so on, and make sure the due dates are readable.
- **Syllabus or schedule PDFs and spreadsheets**, as they are.
- **A `notes.txt` file** for anything the other files don't say: the first and last day of the semester, holidays, class times, or assignments announced in class.

When a class's schedule changes, add the new version (for example, `BIO_100_oct_1.txt`) instead of replacing the old file, so your assistant can compare the two.

Everything in this folder except this README stays off GitHub, because `.gitignore` excludes it. Pasted pages often include your name and grades. See "Privacy" in the main README.
